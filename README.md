# 📊 Student Performance & Placement Dashboard

An interactive dashboard built with Python and Streamlit to analyze student academic performance, attendance, and placement statistics.

## 🚀 Features

- 👨‍🎓 Total student count
- 📚 Average marks analysis
- 📅 Attendance percentage
- 💼 Placement rate
- 📊 Subject-wise performance visualization
- 🔍 Department-wise filtering
- 📋 Interactive student details table
- 📈 Attendance analysis chart
- 🥧 Placement status visualization

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
